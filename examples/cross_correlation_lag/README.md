# Cross-correlation lag illustration

**Status:** Candidate — MATLAB run pending.

## Purpose and typical use

Interactive demonstration with two synthetic shifted pulses.

## Suitable data and inputs

No recording needed. MATLAB desktop dialogs ask for a time shift.

## Requirements

Signal Processing Toolbox.

Check the required MATLAB release and toolboxes locally. Add this folder and its required helpers to the path; avoid adding the entire repository because some scripts share filenames.

## How to use

Run Zuzanna_check_Xcorr_lag.m; use a small shift such as 1 second.

## Example data and outputs

No example recording is included yet. Consult the function interface below for its outputs.

## Parameters and limitations

Dialog cancellation and shifts outside the signal window require care. This is a teaching example, not a validated analysis pipeline.
