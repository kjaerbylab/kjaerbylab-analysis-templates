# Sample data

This folder intentionally does not contain raw recordings.

Use:

```matlab
examples/run_demo_simulated_fp_qc.m
```

to generate a simulated FP signal with:

- exponential bleaching
- motion artifacts
- 405/control channel
- 465/sensor channel
- REM-like ACh transients
- a slow artifact bump
- Gaussian noise

The simulated signal is for testing visualization and code behavior only.
